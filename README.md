# Checklist de Segurança Digital

## Sobre o projeto
Este projeto foi criado com o objetivo de estudar conceitos básicos de cyber segurança.
Ele apresenta um checklist simples de boas práticas para melhorar a segurança digital no dia a dia.

## Objetivo
Ajudar usuários iniciantes a entender como se proteger contra golpes, vazamento de dados e acessos não autorizados.

## Checklist de Boas Práticas

### Senhas
- Utilizar senhas longas e únicas
- Não reutilizar senhas em diferentes servidores
- Utilizar um gerenciador de senhas

### Autenticação 
- Ativar autenticação em dois fatores (2FA)
- Evitar SMS sempre que possível, priorizando apps autenticadores

### Phishing
- Verificar remetente de e-mails
- Não clicar em links suspeitos
- Desconfiar de mensagens urgentes

### Redes
- Evitar redes Wi-Fi públicas
- Utilizar VPN quando necessário

### Atualizações 
- Manter sistema operecional atualizado
- Atualizar aplicativos regularmente

## Ferramentas utilizadas
- Pesquisa teórica
- Documentação
- GitHub
